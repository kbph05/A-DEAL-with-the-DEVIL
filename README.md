# A DEAL with the DEVIL

## Dev
```
npm install
npm run dev      # Vite dev server; add ?seed=abc to the URL for a fixed map
npm test         # map generator tests
npm run build    # static build in dist/ (itch.io / GitHub Pages)
```
Phaser 3 + Vite + TypeScript. Scaled with `Scale.FIT` (720×1280 design size) for mobile and desktop.
